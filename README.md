# Dessert Magic

**Your Ingredients. Your Dessert. A Little Magic.**

Dessert Magic is an interactive dessert discovery website developed as part of the course **Selected Topics: Generative AI Tools (00360714)** at the Technion.

## Project Overview

Dessert Magic helps users discover desserts they can prepare using ingredients they already have at home.

Instead of searching for a specific recipe, users enter their available ingredients, and the website recommends suitable desserts based on ingredient compatibility.

## Key Features

- **Smart Ingredient Search:** Add ingredients freely, with autocomplete suggestions.
- **Top 4 Best Matches:** Discover the four most suitable desserts based on your available ingredients.
- **60 Dessert Recipes:** Explore baked, refrigerated, frozen, and no-bake desserts.
- **Magic Swap:** Find alternative ingredients for selected recipes.
- **Interactive Recipe Cards:** View ingredients, preparation instructions, and estimated preparation times.
- **Visual Dessert Gallery:** Explore desserts through premium, recipe-matched imagery.
- **Responsive Design:** Works on desktop and mobile devices.
